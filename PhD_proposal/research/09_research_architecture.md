# 09 — RESEARCH ARCHITECTURE (proposed integrated control architecture)

Textual block diagram + mathematical structure for the PRIMARY direction D1. All blocks consistent with the CALL's method set ([POLIMI PDF]) and the host group's flatness/NDI heritage ([LITERATURE] S1–S4).

## A. Architectural blocks
```
 Trajectory planner / flat output y(t)
        │  (desired flat output + derivatives)
        ▼
 [FLATNESS / NDI NOMINAL CORE]  ── produces virtual control v_nom (forces/moments)
        │                                 ▲
        │                                 │ structured residual f_res(z;θ̂) + UQ
        ▼                                 │
 [L1-INSPIRED ADAPTIVE AUGMENT]  ────────┘  compensates fast residual uncertainty
        │  (augmented virtual control v*)
        ▼
 [EMBEDDED CONTROL ALLOCATION]  ── sat / rate / degradation-aware mapping v* → u
        │                                 (exploits over-actuation nullspace;
        │                                  health-weighted reallocation on fault)
        ▼
 Actuators (over-actuated thrust-vectoring UAV) ──► plant
        │
        └──► sensor feedback ──► (i) residual ID / parameter update (structured)
                                └─► (ii) UQ → certification margin monitor
```

## B. Mathematical structure [HYPOTHESIS — proposed]
- **Plant (over-actuated):** ẋ = f(x) + g(x) u,  u ∈ ℝ^m,  x ∈ ℝ^n,  m > n_rank; control effectiveness B(x) may degrade: u_eff = Δ(t) u, Δ = diag(δ_i), δ_i∈[δ_min,1].
- **Flatness/NDI nominal core:** choose flat output y = h(x) with y = α(t) reference; invert dynamics to compute nominal virtual control v_nom(x,ẏ_ref) such that tracking holds for nominal model. **[INFERENCE]**
- **Structured residual:** model discrepancy as **physically-structured** term f_res(z;θ̂), z=(x,u,α,β), where the structure is derived from first principles + sparse/parametric identification (hybrid first-principles + SINDy-style sparse terms), NOT a black box. UQ: GP or set-membership gives bound ‖f_res‖ ≤ ρ(x,t) with confidence. **[HYPOTHESIS]**
- **L1-inspired augmentation:** add adaptive term to virtual control, v* = v_nom + v_ad, where v_ad is generated by an L1-style low-pass filtered adaptive law (decoupling principle) that compensates residual uncertainty with a *verifiable robustness/transient margin* independent of PE. **[HYPOTHESIS]** Differentiator vs MRAC (Falconí) and vs H∞ (Lovera B9/B10).
- **Embedded CA:** solve, at control rate, u = argmin_{u∈𝒰} ‖W_v·(B(x)u − v*)‖_p + ‖W_u·(u−u_prev)‖_q,  𝒰 = {saturation, rate, Δ-health constraints}. Nullspace exploited for secondary goals (efficiency, degradation load-balancing). CA is INSIDE the loop (not downstream) so its feasibility enters the stability proof. **[HYPOTHESIS]**
- **Certification/interpretability monitor:** combine (a) L1 robustness margin, (b) residual UQ bound ρ, (c) CA μ-analysis/feasibility → a single verifiable stability/performance statement updated across fidelity levels.

## C. Why this structure is defensible vs adversaries [INFERENCE]
- vs **Gahlawat L1-GP/CL1-GP**: we add embedded CA + over-actuation + degradation + structured (not black-box) residual.
- vs **B1 (SINDy-CA)**: we add flatness/NDI core + L1-inspired compensation + certification argument (B1 has no L1, no cert).
- vs **Falconí / B7 / B8 (MRAC/adaptive-CA)**: we use L1-inspired (decoupling/transient guarantee) not MRAC; we add structured residual + certification.
- vs **Lovera B9/B10 (H∞+CA)**: we use model-based flatness/NDI + data-informed structured residual + L1, not H∞/μ-only; we add explicit multi-fidelity validation.
- vs **B11 (DI+CA FTC)**: we add L1-inspired + structured data-informed residual + certification, not DI+optimization-CA alone.
