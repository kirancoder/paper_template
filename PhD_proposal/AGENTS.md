# PhD Proposal Research Workspace

## Scope restriction — CRITICAL

This directory is the ONLY source directory for the PhD proposal research task.

Allowed research files:

`PhD_proposal/**`

Do NOT read, search, glob, grep, inspect, or use files from:

* the parent `paper_template/` directory
* `GNC_paper/`
* `.git/`
* any other project folder
* any `.tex`, `.bib`, `.md`, `.qmd`, source-code, or configuration files outside `PhD_proposal/`

The `paper_template` repository contains unrelated academic-paper files. Ignore them completely.

## Research source policy

For the PhD proposal research task:

1. Search ONLY the PDF documents contained inside `PhD_proposal/`.
2. Treat those PDFs as the primary source material.
3. Do not use other repository files as background context.
4. Do not infer the contents of files that you have not explicitly read.
5. Do not search the rest of the repository merely to find potentially useful references.
6. Do not modify any files in this directory unless explicitly instructed.

## External literature research

When external web research is explicitly requested:

* use external scholarly/web sources only to supplement the PDF research;
* clearly distinguish PDF-derived information from external literature;
* never replace information from the supplied PDFs with assumptions;
* record the exact external source for every important claim;
* prioritize original papers, journal pages, IEEE/AIAA/Springer/Elsevier pages, DOI records, and official institutional sources.

## Research discipline

For every important conclusion classify it as one of:

[PDF SOURCE]
Directly supported by the supplied PDFs.

[EXTERNAL SOURCE]
Supported by an independently verified external publication.

[INFERENCE]
A conclusion derived by comparing multiple sources.

[RESEARCH GAP]
A possible gap that requires further verification.

[HYPOTHESIS]
A proposed research hypothesis, not an established fact.

Never present an inference or hypothesis as an established fact.

## Continuous research

Do not stop after the first literature pass.

Iteratively:

1. search;
2. read;
3. compare;
4. identify limitations;
5. formulate possible gaps;
6. search specifically for papers that could invalidate those gaps;
7. revise the gap;
8. compare competing research directions;
9. refine the final recommendation.

The goal is depth and technical defensibility, not the largest possible bibliography.
